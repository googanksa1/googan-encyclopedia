# أدوات الكتب: من ملف PDF إلى كتاب يُقلَّب على مكتبة جوجان

هذه هي الأدوات نفسها التي حُوّل بها كتاب «البقاء متزناً». تُشغَّل من جذر المستودع، بالترتيب. كل خطوة تطبع ما فعلته، فلا تنتقل للتالية قبل أن تتحقق من نتيجتها.

المتطلبات (مرة واحدة): `pip install pymupdf pillow fonttools`

## 1. ختم سطر جوجان أسفل كل صفحة
```
python3 tools/book_tools/book_footer.py الكتاب-الأصلي.pdf الكتاب-جوجان.pdf
```
- يضيف بخط Cairo الرمادي الصغير: «تمت الترجمة لمؤسسة المشعل الخيرية وبرنامج قويم | ترجمة وتدقيق: شركة جوجان لخدمات الأعمال | googantranslation.com» على كل الصفحات ما عدا الغلاف.
- **تحقق:** افتح الملف الناتج وانظر إلى 3 أو 4 صفحات: السطر لا يغطي رقم الصفحة أو النص. إن غطّاه فأعد التشغيل مع `--bottom 3` أو `--bottom 10`.
- لنص آخر: `--text "..."`.
- الأداة **لا** تغيّر أي نص داخل الكتاب. الاسم القديم «شركة وكالة جوجان» إن وُجد يُصحَّح في ملف المصمم، أو بتعديل موضعي منفصل.

## 2. تحويل الصفحات إلى صور
```
python3 tools/book_tools/book_pages.py الكتاب-جوجان.pdf اسم-الكتاب-بالإنجليزية
```
- `اسم-الكتاب-بالإنجليزية` هو الـ slug الذي يظهر في الرابط، بحروف إنجليزية صغيرة وشرطات، مثل `staying-sober`.
- يكتب الصور في `tools/content/books/<slug>-pages/` بالأسماء `001.webp`، `002.webp`… بعرض 840 بكسل، بين 50 و80 كيلوبايت تقريباً للصفحة. ملف الـPDF نفسه لا يُرفع أبداً.
- إن كانت الصفحة الأولى غلافاً مفروداً (أمامي وكعب وخلفي معاً)، يقسمها تلقائياً: الغلاف الأمامي يصبح `001.webp`، والخلفي آخر صورة.
- **تحقق:** افتح `001.webp`. إن ظهر الغلاف الخلفي بدل الأمامي فأعد التشغيل مع `--swap-cover`.
- **القاعدة:** الصورة رقم N هي صفحة الـPDF رقم N.

## 3. ملف الفهرس ونص الصفحات الأولى
اكتب ملفاً نصياً `toc.txt` من صفحة المحتويات في الكتاب نفسه، سطراً لكل قسم:
```
# رقم صفحة PDF | العنوان | العنوان الفرعي (اختياري) | الرقم المطبوع (اختياري)
10 | إهداء
12 | مقدمة المؤسسة
32 | الفصل الأول | الانتكاسة بالنسبة لمرض الإدمان
```
- **رقم صفحة PDF** هو الرقم الذي يُظهره برنامج قراءة PDF لصفحة بداية القسم، وليس الرقم المطبوع على الورقة.
- الرقم المطبوع، إن لم تكتبه، يُحسب على أنه رقم PDF ناقص 1، وهذا صحيح في كتب المشعل لأن الصفحة الأولى غلاف.

ثم شغّل:
```
python3 tools/book_tools/book_contents.py الكتاب-جوجان.pdf <slug> toc.txt
```
- يكتب `tools/content/books/<slug>.json`: الفصول بأرقام صفحاتها، ونص كل قسم.
- يكتشف تلقائياً إن كان الكتاب بالخطوط العربية القديمة (منى، أحمد، حسان)، ويفك ترميزها عبر `legacy_text.py` و`namemap.json`.
- إن طبع **UNKNOWN GLYPHS**: أضف أسماء الرموز المذكورة إلى `namemap.json` مع الحرف العربي المقابل لكل منها، ثم أعد التشغيل.

## 4. تسجيل الكتاب في الموقع
أضف عنصراً إلى القائمة `BOOKS` في `tools/books.py` على نمط الكتاب الأول:
```python
{
    "slug": "<slug>",
    "file": "<slug>.json",
    "title": "العنوان العربي كما على الغلاف",
    "orig": "Original English Title",          # من صفحة الحقوق في الكتاب
    "authors": "Author One & Author Two",
    "authors_ar": "المؤلف الأول والمؤلف الثاني",
    "desc": "وصف من جملة أو جملتين يظهر في جوجل وفي صفحة الكتاب.",
    "credit": "تمت الترجمة لجمعية المشعل الخيرية وقويم. ترجمة وتدقيق: شركة جوجان لخدمات الأعمال",
    "preview": (0, 1, 3),   # أرقام الأقسام (من 0) التي تظهر نصاً مقروءاً في صفحة الكتاب
}
```
- لا تكتب في العنوان الأصلي أو المؤلفين أو الوصف إلا ما في الكتاب نفسه.

## 5. البناء والتحقق والنشر
```
python3 tools/build4.py --snapshot site
```
- افتح `site/_library/books/<slug>/index.html` و`.../read/` في المتصفح.
- **تحقق من:** الغلاف، ونص الصفحات الأولى، وأن الضغط على كل فصل في الفهرس يفتح صفحته الصحيحة.
- ثم: `git add -A && git commit && git push`. ينشر Cloudflare الموقع خلال دقيقة أو دقيقتين على `library.bloggoogan.com/books/<slug>/`.

## ملفات المجلد
| الملف | عمله |
|---|---|
| `book_footer.py` | ختم سطر جوجان على كل صفحة |
| `book_pages.py` | تحويل الصفحات إلى صور WebP، وقسمة الغلاف المفرود |
| `book_contents.py` | إنشاء ملف الفهرس ونص الأقسام |
| `legacy_text.py` | قراءة نص الـPDF، بما فيه الخطوط العربية القديمة |
| `namemap.json` | جدول تحويل أسماء رموز الخطوط القديمة إلى حروف عربية |
| `fonts/` | خط Cairo للسطر المختوم (رخصة OFL مرفقة) |
